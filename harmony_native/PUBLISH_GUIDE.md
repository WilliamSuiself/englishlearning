## 应用介绍（详细描述，400-1000字，当前约589字）
HEIDI英语学习是一款专注于英语能力提升的学习工具，将背单词、习题练习、阅读训练、学习统计四大模块整合在一个简洁的界面中，帮助你利用碎片时间系统提升英语水平。

【智能背单词】内置超过12000个精选词汇，覆盖中考、四六级、考研、托福等多个难度层级，可按等级筛选学习。卡片式翻转设计，点击查看音标、词性、释义与例句，支持一键发音跟读，并可根据掌握程度标记生词，循环巩固记忆。

【习题练习】涵盖词汇辨析、语法运用、阅读理解等多种题型，作答后即时判断对错并给出详细解析，帮助你查漏补缺，巩固知识点。

【阅读训练】精选3700余篇难度分级的英文阅读材料，配套理解测试题，检验阅读效果。支持整篇朗读功能，边听边读，同步锻炼听力与语感。

【学习统计】自动记录背词数量、答题正确率、阅读完成情况以及连续学习天数，可视化呈现学习进度，让每一次坚持都看得见。

【特色亮点】
· 离线可用：词库、题库、阅读材料均已内置，无网络也能随时学习；
· 真人发音：接入 HarmonyOS 语音引擎，支持在线/离线双模式发音；
· 简洁纯粹：全程无广告干扰，专注学习本身；
· 隐私安全：学习记录仅保存在本机，不上传、不收集任何个人信息。

无论你是备战中高考的学生、冲刺四六级和考研的大学生，还是希望提升职场英语或备考雅思托福的职场人士，HEIDI英语学习都能陪你稳步进阶，让英语学习变得更简单、更高效。

## 上架步骤

### 1. 准备签名材料
使用 DevEco Studio 自动签名：
- File → Project Structure → Signing Configs
- 登录华为账号
- 选择 release 模式，生成 p12、p7b、cer

### 2. 打包 release HAP
- Build → Build Hap(s)/APP(s) → Build App(s)
- 选择 release 模式
- 产物路径：`entry/build/default/outputs/default/entry-default-signed.hap`

### 3. 登录 AGC
- 访问 https://developer.huawei.com/consumer/cn/service/josp/agc/index.html
- 创建应用，填写包名 `com.englishlearning.suiyunhai`

### 4. 填写应用信息
- 上传应用图标（1024×1024）
- 上传应用截图（建议 3-5 张）
- 填写应用简介和详细介绍
- 选择应用分类
- 上传隐私政策

### 5. 提交审核
- 上传 HAP 包
- 填写版本说明
- 提交审核

### 6. 等待审核结果
- 一般 1-3 个工作日
- 审核通过后即可在华为应用市场上架

## 注意事项

1. **包名一致性**：AGC 创建应用时的包名必须与 `AppScope/app.json5` 中的 `bundleName` 一致
2. **签名一致性**：release 签名的 p7b 中的 bundleName 必须与工程 bundleName 一致
3. **图标规范**：图标不能包含圆角，华为系统会自动添加
4. **截图规范**：建议使用真机截图，尺寸 2160×1080 或类似比例
5. **隐私政策**：必须提供有效的隐私政策 URL
6. **应用描述**：避免使用绝对化用语（如"最好"、"第一"等）
